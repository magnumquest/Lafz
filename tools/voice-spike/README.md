# Voice model evaluation tools

These standalone scripts support development of Lafz's optional offline voice typing. They are not part of the Android app's runtime. Models, datasets and generated files are stored outside the repository; nothing from this directory is bundled into the APK.

The scripts use public speech datasets and model formats. Review each dataset and model's license before downloading, using or redistributing it. Run scripts with `--help` for available arguments and install only the dependencies needed for the selected evaluation tool.
